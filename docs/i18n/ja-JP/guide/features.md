# 機能概要 (Features)

::: warning Translation Notice
このページは [中国語原文](../../../guide/features.md) を基準にした要約です。詳細な機能一覧は原文を参照してください。
:::

Momei は **AI 駆動・ネイティブ国際化** 対応のモダンブログプラットフォームです。

## 1. AI 創作アシスタント

- **スマートタイトル提案**: 本文から SEO に最適なタイトルを自動生成
- **自動要約生成**: 記事の要約をワンクリックで生成し SEO メタ情報を自動設定
- **スマートタグ付け**: 内容を分析して適切なタグを自動推薦
- **スキャフォールディング**: AI が論理構成を提案し記事の枠組みを素早く構築
- **SEO Slug 生成**: タイトルから簡潔で可読性の高い URL を自動生成
- **ワンクリック多言語翻訳**: Markdown 形式を完全保持したまま多言語へ翻訳
- **AI 画像生成**: DALL-E 3 などと連携し記事に合わせたカバー画像を生成
- **音声入力**: Web Speech API とクラウド ASR の両モードに対応
- **インスピレーション収集**: 断片的なアイデアを素早く収集・分類し記事化

## 2. 多言語・国際化

- **翻訳クラスター管理**: 同一記事の多言語版を管理画面で統合管理
- **スマートルーティング**: 多言語 URL 戦略と `hreflang` タグを自動出力
- **言語間ジャンプ**: 読者が言語を切り替えると対応する翻訳版へ自動遷移
- **多言語カテゴリ・タグ**: カテゴリとタグも多言語に対応

## 3. コンテンツ管理

- **トップページ編集**: 最新記事と人気記事の二重ブロック構成
- **ページネーション・ナビゲーション**: 前後の記事リンクを自動生成
- **関連記事レコメンド**: カテゴリとタグに基づき関連記事を自動表示
- **記事ピン留め**: 特定記事をトップに固定表示

## 4. 管理機能

- **ダッシュボード**: 投稿数、ビュー数、タスク状況を一元管理
- **メディア管理**: 画像・音声ファイルのアップロードと管理
- **コメント管理**: スパム対策・承認フロー・ブラックリスト
- **ユーザー管理**: ロールベースの権限管理（管理者・投稿者・読者）
- **システム設定**: 13 カテゴリの設定画面（サイト・AI・メール・ストレージ等）
- **テーマ設定**: カラーカスタマイズ・ダークモード・背景設定

## 5. AI 配分ガバナンス

- **クォータ管理**: ユーザー・ロールごとの AI 使用上限設定
- **コスト管理**: AI プロバイダー別の料金マッピングとコスト監視
- **アラート機能**: クォータ超過や障害発生時の通知
- **フォールバック**: メインプロバイダー障害時の代替プロバイダー自動切替

## 6. 配信・SEO

- **RSS / Atom / JSON Feed**: 全文配信に対応したマルチフィード
- **サイトマップ自動生成**: 多言語サイトマップに対応
- **SEO メタ情報**: 記事ごとのカスタム SEO 設定が可能
- **外部配信連携**: WechatSync・Memos など外部プラットフォームへの自動配信

## 7. 移行ツール

- **CLI 一括インポート**: Hexo / Hugo / WordPress 形式に対応
- **画像自動移行**: 外部 URL の一括ダウンロードと書換え
- **リンク管理**: 外部リンクのリダイレクト管理と健全性チェック
- **API クライアント**: CLI / MCP 経由でプログラムから操作可能
