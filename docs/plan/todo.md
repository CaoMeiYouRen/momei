- [ ] **85.1 移动端视觉与回归门禁（P1）**
    - [x] **85.1.1 移动视觉基线与预算**
        - 目标: 新增 `390×844`（DPR 3）移动视觉层，覆盖 10–12 条 reader 路由，动态区域以 `[data-visual-mask]` 遮蔽后采集基线。
        - 验收: 移动脚本独立运行通过；基线覆盖 ≥10 条路由；桌面视觉 32/32 不回归。
        - 交付物: 移动脚本、基线、证据。
        - 依赖: 现有视觉基建与 TEST_MODE 种子数据。
    - [x] **85.1.2 移动 parity 与 CI 接入**
        - 目标: 把移动视口纳入 parity 预算并接入 CI 视觉任务，失败可归因。
        - 验收: CI 中移动视觉任务通过；预算按路由分档；变化可定位到路由与区域。
        - 交付物: 配置 / workflow、CI 回执。
        - 依赖: 85.1.1。
    - [x] **85.1.3 移动关键路径 E2E**
        - 目标: 覆盖菜单开关、搜索打开/关闭、分页、目录入口、表单提交入口等公开页关键路径。
        - 验收: ≥8 条断言在 `responsive.e2e.test.ts` 的 iPhone 13 device override 下通过（不新增 Playwright project）；桌面 E2E 不回归。
        - 交付物: E2E 用例、运行证据。
        - 依赖: 85.1.1。

- [ ] **85.2 阅读页移动体验（P1）**
    - [x] **85.2.1 内容溢出与代码复制**
        - 目标: markdown 表格横向滚动且容器可聚焦、不产生页面级横向滚动；长 URL / 公式 / 行内代码不溢出；代码复制按钮在粗指针设备常显可点。
        - 验收: 360–430px 下文章页无页面级横向滚动；表格容器可键盘滚动；复制按钮在 `(hover: none)` 可见并可复制成功。
        - 交付物: 样式改动、移动快照、定向 E2E。
        - 依赖: 85.1。
    - [x] **85.2.2 移动目录与分享**
        - 目标: 移动端提供目录入口（打开 / 跳转 / 关闭），分享与作者元信息正常换行，触控目标 ≥44px。
        - 验收: 目录可打开并跳转到对应标题；关闭后不残留滚动锁；分享按钮触控尺寸达标；移动快照通过。
        - 交付物: 目录组件改动、快照。
        - 依赖: 85.2.1。
    - [ ] **85.2.3 阅读页对账收口**
        - 目标: 桌面与移动双向快照对账，确认无回归后收口。
        - 验收: 桌面 32/32、移动基线通过、parity 除既有差异外无新增失败。
        - 交付物: 对账证据。
        - 依赖: 85.2.2。

- [ ] **85.3 全局壳层与触控目标（P2，确认档 ROI 1.33）**
    - [ ] **85.3.1 抽屉可访问性与滚动锁**
        - 目标: 抽屉打开后焦点进入、Esc / 关闭按钮可关闭、关闭后焦点返回触发按钮、背景滚动锁定、`aria-expanded` 正确。
        - 验收: 键盘可完成打开→关闭全流程；焦点不逃逸；`aria-expanded` 随状态变化；E2E 断言通过。
        - 交付物: 壳层改动、E2E。
        - 依赖: 85.1。**Kill-switch**: 若需替换共享抽屉组件或改动 >3 个共享组件，本阶段只落其余子项并退回 backlog #11。
    - [ ] **85.3.2 安全区与视口高度**
        - 目标: header / footer / 悬浮入口使用 `env(safe-area-inset-*)`；`100vh` → `100dvh` 带回退。
        - 验收: E2E 取值断言 `env(safe-area-inset-*)` 与 fallback；`100dvh` 计算值正确且 `vh` 回退成对存在（脚本 grep）；公开页无新增布局跳动。真机浏览器栏遮挡单列人工验证项。
        - 交付物: 样式改动、快照。
        - 依赖: 85.3.1。
    - [ ] **85.3.3 触控目标与 hover 兜底**
        - 目标: 抽样审计公开页 ≥20 个主要可点击元素 ≥44×44px；hover-only 交互在粗指针设备有可见替代。
        - 验收: 审计清单落证据；不达标项修复或登记理由；移动 E2E 覆盖至少 2 个 hover-only 交互。
        - 交付物: 审计清单、样式 / 组件改动。
        - 依赖: 85.3.2。

- [ ] **85.4 表单与输入体验（P2，确认档 ROI 1.33）**
    - [ ] **85.4.1 输入字号与键盘属性**
        - 目标: 移动端输入框计算字号 ≥16px；邮箱 / 密码 / URL 等字段具备正确 `type` / `inputmode` / `autocomplete` / `enterkeyhint`。
        - 验收: 移动端 `getComputedStyle` 字号 ≥16px；`type` / `inputmode` / `autocomplete` / `enterkeyhint` 由 E2E 断言；桌面视觉不回归。
        - 交付物: 样式与模板改动、证据。
        - 依赖: 85.1。
    - [ ] **85.4.2 键盘遮挡与提交可达**
        - 目标: 键盘弹出时提交按钮可达（sticky + safe-area 或 `visualViewport`），密码显隐与粘贴可用。
        - 验收: `visualViewport` 高度收缩模拟后提交按钮 boundingBox 落在可视区内；密码显隐切换可点；不引入新依赖。真机键盘遮挡单列人工验证项。
        - 交付物: 表单改动、E2E。**Kill-switch**: 若需引入新依赖或改提交协议，只落 85.4.1 并登记键盘方案评估结论。
        - 依赖: 85.4.1。
    - [ ] **85.4.3 校验错误可见性**
        - 目标: 提交失败时错误信息可见并聚焦首个错误字段。
        - 验收: 移动 E2E 覆盖空表单 / 非法邮箱提交；错误文案在视口内；焦点落到首个错误字段。
        - 交付物: E2E、证据。
        - 依赖: 85.4.2。

        - 验收: 移动快照通过；分页可点；无页面级横向滚动。
        - 交付物: 样式 / 模板微调、快照。
        - 依赖: 85.1。
    - [ ] **85.5.2 分类标签归档与空态**

        - 验收: 移动快照通过；空态与骨架屏各自独立基线（或两态卡片区 + 分页区高度差 ≤24px）。
